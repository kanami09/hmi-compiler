# 指针、波形与二维码

[项目首页](../../../README.md) · [页面编译器](../README.md) · [控件总览](controls.md)

三类均需要 `x/y/w/h`，支持 `down/up`，`vscope/sendkey` 默认 0。单色模式不需要字库或图片。

## 指针

```toml
[[objects]]
name = "z0"
type = "gauge"
properties = { x = 60, y = 40, w = 200, h = 200, val = 45 }
```

`val` 为 0～360，默认 0；默认背景 `bco=65535`、指针色 `pco=0`、中心圆色 `pco2=63488`。`sta` 为 0 切图／1 单色／2 图片／3 透明，默认 1；透明仅 X 系列支持。工具不自动创建表盘背景。

| 指针形状属性 | 默认值与范围 |
|---|---|
| up | 尖长，默认 32767 表示自动；有符号 16 位，范围 -32768～32767 |
| down | 尾长，默认 30；有符号 16 位，范围 -32768～32767 |
| hig | 中心圆直径，默认 24，范围 0～100；0 表示无中心圆 |
| vvs0、vvs1、vvs2 | 尖宽、腰宽、尾宽，默认 1／7／2，范围均为 0～128 |

## 波形

```toml
[[objects]]
name = "s0"
type = "waveform"
properties = { x = 20, y = 40, w = 280, h = 160, ch = 2 }
```

`ch` 为 1～4，默认 1。`sta` 为 0 切图／1 单色／2 图片／3 透明，默认 1；默认 `bco=0`、网格色 `gdc=1024`。减少通道数不会删除其他通道颜色，曲线数据由运行时指令提供。

| 波形属性 | 默认值与范围 |
|---|---|
| dir | 默认 0；0 左到右、1 右到左、2 靠右对齐 |
| gdw、gdh | 网格宽／高，默认 40，范围 0～255；0 关闭对应网格 |
| dis | 数据缩放百分比，默认 100，范围 10～1000，按两字节保存 |
| pco0、pco1、pco2、pco3 | 通道颜色，默认 64495／65519／63488／2016，范围 0～65535 |

指针、波形的图片和切图要求见[图片模式](controls-images.md)。

## 二维码

```toml
[[objects]]
name = "qr0"
type = "qrcode"
properties = { x = 60, y = 40, w = 200, h = 200, txt = "HMI-A", txt_maxl = 16 }
```

`txt` 必填，`txt_maxl` 为 0～192 个 UTF-8 字节，默认 16。默认背景 `bco=65535`、前景 `pco=0`。二维码由上位机或屏幕根据文本生成，不需要字库或预先制作图片。

此处 `sta=0` 无中心 LOGO、`sta=1` 使用 LOGO，默认 0。开启时 `pic` 必须引用有效普通图片；关闭时允许省略或保留非活动图片引用。LOGO 不要求全屏，控件尺寸不会缩放共享图片。
