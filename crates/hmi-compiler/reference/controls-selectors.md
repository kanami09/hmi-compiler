# 状态开关与文本选择

[项目首页](../../../README.md) · [页面编译器](../README.md) · [控件总览](controls.md)

本页四类控件在内置配置中仅对 X543 开放。它们均需要 `x/y/w/h` 和字体引用，支持 `down/up`；`vscope/sendkey` 默认 0。

## 状态开关

`type = "switch"`。`val` 为 0／1，默认 0；`dez=0` 横向、`dez=1` 竖向，默认 0。`txt` 默认空，可写如 `0/1` 的标签；`txt_maxl` 为 0～24，默认 24。`dis` 为 0～100，默认 100。

状态 0 的 `bco/pco` 默认 50712／65535，状态 1 的 `bco2/pco2` 默认 1024／65535；`pco1` 默认 0。颜色均为 RGB565 整数。

## 下拉框

```toml
[[objects]]
name = "cb0"
type = "combo_box"
properties = { x = 20, y = 20, w = 300, h = 84, font = { ref = "ui_font" }, path = "A\nB\nC", path_m = 64, txt = "LABEL", val = 1 }
```

`path` 是每行一项的选项文本，不是文件路径。`txt` 独立保存，构建时不会因为 `val=1` 就将示例中的 `LABEL` 改成 `B`。

| 下拉框属性 | 默认值与范围 |
|---|---|
| path、path_m | 选项集合默认空，容量默认 64，范围 0～65535 字节 |
| txt、txt_maxl | 独立保存的文本默认空，容量默认 16，范围 0～65535 字节 |
| val | 初始选择值，0～255、默认 0，不在编译时据此重写 txt |
| dir、qty | 展开方向 0 上／1 下／2 左／3 右，默认 1；展开数量 1～254，默认 2 |
| hig、down | 单元格高／宽 16～255，默认 72；展开状态 0 收缩／1 展开，默认 0 |
| up、pco3 | 箭头显示 0／1，默认 1；箭头颜色默认 42292 |
| bco1、pco1、bco2、pco2 | 普通单元格背景／字体默认 65535／0，选中背景／字体默认 31／65535 |
| mode、wid | 滑动标识类型 0～2、默认 2；标识高／宽 8～255、默认 12 |
| vvs0、vvs1 | 单元格间距、标识间距，0～255，默认 8／2 |
| ch、dis | 滑动惯性 0～32、默认 8；圆角比例 0～100、默认 25 |

另支持 `xcen/ycen`（0～2，默认 1）和 `spax`（0～255，默认 0）。

## 选择文本

`type = "text_select"`。`path/path_m` 的选项和容量规则与下拉框相同，默认空／64。`val` 为 0～4294967295，默认 0。`txt` 是运行时只读结果，不能作为初始输入；也不按 `val` 预先填入某项文字。

## 滑动文本

```toml
[[objects]]
name = "slt0"
type = "sliding_text"
properties = { x = 20, y = 20, w = 440, h = 232, font = { ref = "ui_font" }, txt = "A\nB\nC\nD", txt_maxl = 64, path_m = 0 }
```

正文使用必填的 `txt`，`txt_maxl` 默认 64。`path_m` 是行缓冲容量，默认 0 表示按 `txt_maxl` 取值；可用行数为其一半。这里不是选项集合的字节长度。

支持 `xcen`（0～2）、`left`（0 隐藏／1 操作时显示／2 始终显示进度条，默认 1）、`ch`（0～32，默认 8）、`isbr`（0／1，默认 0）和 `spax/spay`（0～255，默认 0）。`maxval_y` 是运行时只读值；当前不接受初始滚动位置。

## 共同外观与换行

下拉框、选择文本和滑动文本默认单色白底黑字、边框颜色 0、宽度 2，支持[图片背景和透明背景](controls-images.md)。下拉框／滑动文本的 `style` 为 0～4，选择文本为 0～1，默认均为 0。

选项和正文可使用 TOML 转义换行或多行字符串。LF、CRLF 均按 CRLF 保存，空行和末尾换行保留，容量按转换后的 UTF-8 字节数检查；单独的 CR 不接受。
