# 文件与数据记录

[项目首页](../../../README.md) · [页面编译器](../README.md) · [控件总览](controls.md)

本页控件在内置配置中仅对 X543 开放。路径指向屏幕运行环境，构建时不会读取或修改 SD 卡、虚拟 SD 或其中的数据文件。

## 文件浏览器

```toml
[[objects]]
name = "fb0"
type = "file_browser"
properties = { x = 20, y = 20, w = 440, h = 232, font = { ref = "ui_font" }, dir = "sd0/", filter = "*.txt|*.data" }
events = { up = "events/fb0.up.s" }
```

`pic1` 是文件夹图标，`pic2` 是默认文件图标，均可引用内嵌普通图片。省略时使用[内置图标](../../../data/icons/README.md)，显式指定时不会自动替换，不允许 `none`。多个浏览器共享所需内置资源，图片 ID 仍按最终资源列表分配。

| 浏览器属性 | 默认值与范围 |
|---|---|
| dir | 运行时目录，默认 sd0/，最大 255 个 UTF-8 字节 |
| filter | 文件名过滤条件，默认 *，最大 64 个 UTF-8 字节，可用 `\|` 分隔模式 |
| buffsize | 目录结果缓冲区字节数，u32，默认 32000；本工具不估算运行时可用内存 |
| psta | 是否支持子目录，0／1、默认 0 |
| fwarning | 编译时非 UTF-8 警告开关，0／1、默认 1；运行脚本不能读写 |
| left、ch | 进度条显示 0～2、默认 1；滑动惯性 0～32、默认 8 |
| dis、spax、spay | 文件名行数、横向／纵向间距，0～255，默认 3／24／8 |

默认单色白底黑字，`style=2`（0～4）、`borderc=0`、`borderw=2`、`xcen=1`（0～2），选中颜色 `bco2=31/pco2=65535`。背景模式见[图片模式](controls-images.md)。

支持 `down/up`。`vscope` 默认 0；即使设为全局，`txt` 也只能在所属页读取。`txt/qty` 等结果由运行环境提供，不能配置初始文件列表；当前不接受初始 `val`。`fwarning` 可以在页面源码设置，不能由运行脚本读写。

## 自定义文件图标

`vvs2` 使用有序映射数组：

```toml
[[objects]]
name = "fb0"
type = "file_browser"

[objects.properties]
x = 20
y = 20
w = 440
h = 200
font = { ref = "ui_font" }
vvs2 = [
    { pattern = "*.txt", pic = { ref = "text_icon" } },
    { pattern = "*.log", pic = { ref = "log_icon" } },
]
```

也可使用原生数值字符串，如 `vvs2 = "*.txt/2*.log/3"`。数字按最终图片 ID 解释；推荐使用符号引用，方便重排资源。

- `pattern` 支持 `*.后缀`；后缀由 ASCII 字母、数字、下划线、连字符或点组成。
- 相同后缀按 ASCII 大小写不敏感检查，不能重复。
- 映射必须引用有效内嵌图片，不能使用 `none`、保留值或外部资产。
- 文件夹继续使用 `pic1`，未匹配文件使用 `pic2`；空数组表示没有自定义映射。
- 最终映射字符串容量为 64 个 UTF-8 字节，按实际数字 ID 计算，超限时报错。

## 文件流

```toml
[[objects]]
name = "fs0"
type = "file_stream"
```

文件流为非可视控件，强制 `vscope=0`，不接受几何、字体、图片或事件槽。初始状态为未打开；在所属页面的其他事件中调用方法完成文件操作。

脚本可设置 `val`、读取 `qty/en`，`qty/en` 只读，不能跨页访问或调用。方法参数和读写效果尚未完整纳入静态分析。

## 数据记录

```toml
[[objects]]
name = "records"
type = "data_record"
properties = { x = 20, y = 20, w = 440, h = 232, font = { ref = "ui_font" }, path = "sd0/records.data", lenth = 32, maxval = 16, dez = 2, format = "200^200", dir = "T^V" }
```

强制 `vscope=1`，每个工程最多 8 个，支持 `down/up`。控件使用屏幕的数据文件，不会把记录内容嵌入 HMI。

| 文件与结构属性 | 含义和范围 |
|---|---|
| path | 必填，屏幕运行时的数据文件路径，1～255 个 UTF-8 字节；不是本机输入路径 |
| lenth | 必填，每条记录的最大字节数，0～255；不含文件槽位末尾的 NUL；保留原生属性名拼写 |
| maxval | 必填，数据文件的最大记录数，按 u32 保存；超过后由控件循环覆盖旧记录 |
| dez | 必填，列数，1～12，按 u16 保存 |
| format | 默认空字符串，由控件处理默认列宽；也可用 `^` 分隔列宽，例如 200^200；最多 256 个 UTF-8 字节 |
| dir | 默认空字符串，表示隐藏表头；也可用 `^` 分隔标题，例如 T^V；最多 255 个 UTF-8 字节。这是表头，不是目录 |
| mode | 默认 1，路径下文件不存在时允许原生环境自动创建；0 表示不允许创建，需自行提供结构匹配的文件 |
| order | 默认 0，新数据在前；1 表示新数据在后 |
| dis | 默认 1，允许触摸选中；0 表示不允许 |

`lenth/maxval/dez` 可配置初值，运行脚本中只读。修改结构后，已有数据文件可能不再匹配，应使用新路径或自行迁移数据。本工具不生成、修改、删除 `.data` 文件：`mode=1` 时由原生运行环境按需创建，`mode=0` 时由用户提供已有文件。

| 外观属性 | 默认值与范围 |
|---|---|
| `style/xcen` | 2／0，范围分别为 0～4／0～2 |
| `hig` | 行高，1～255，默认 72 |
| `left/ch/spax` | 进度条显示 0～2（默认 1）、惯性 0～32（默认 8）、间距 0～255（默认 0） |
| `gdc/gdw/gdh` | 表格线色默认 50712，线宽均为 0～255、默认 1；0 关闭 |
| `bco1/pco1` | 表头背景／字体，默认 23765／65535 |
| `bco2/pco2` | 选中背景／字体，默认 31／65535 |

背景支持[图片、切图、单色和透明](controls-images.md)。`val` 默认 4294967295 表示未选中；`val/val_x/val_y` 可配置 u32 初值，滚动值默认 0。`qty/txt/maxval_x/maxval_y` 是运行时只读结果，不会根据初值编造记录。

`link-map.json` 的 `runtime_files` 汇总初始设备路径、结构、使用控件和自动创建需求。相同路径的记录结构必须一致；同一路径不能混用为不同种类的运行资源。脚本后续更改路径的行为不能由初始依赖表推断。
