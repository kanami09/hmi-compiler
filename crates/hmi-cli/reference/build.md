# 构建、缓存与清理

[项目首页](../../../README.md) · [工程管理工具](../README.md) · [工程文件](project.md) · [日志与自动化](automation.md)

## 增量构建与全量重建

```powershell
hmi build panel
hmi build panel -j 4 -o output/Panel.HMI
hmi rebuild panel
```

`build` 按输入内容复用编译、媒体处理和链接结果；`rebuild` 跳过派生缓存，执行全量重建。两者都遵循工程中声明的媒体输入方式：全量重建不会把 `native` 输入改成原图转码，也不会禁止符合条件的 `original` 附件复用。

未指定 `-o` 时，使用 `build.output`；也未配置该字段时，输出到 `dist/<工程名>/<工程名>.HMI`。统一入口同时在 HMI 所在目录生成 `link-map.json`，记录最终页面、控件、资源及运行时文件需求。

源文件、脚本、资产描述和原始附件必须实际存在且有效，缓存不能代替缺失输入。

## 并行任务

`-j N` 或 `--jobs N` 设置并行任务上限，范围为 1～256。默认按可用 CPU 数量运行，最多 8 个任务；媒体任务另限为最多 2 个并发，控制解码和编码期间的内存占用。`-j 1` 使用串行处理。

独立页面和媒体可以交错完成，最终页面、控件及资源顺序仍以清单为准。同一缓存单元不会同时写入。出现错误后停止领取新任务，已运行的任务结束后汇总结果；其中已成功处理的缓存可留供下次构建使用。

## 缓存行为

| 变化 | 构建行为 |
|---|---|
| 修改页面属性或事件脚本 | 重新编译对应页面，再检查工程引用和链接结果 |
| 修改一项媒体或其处理参数 | 重新处理对应媒体；页面的显式几何保持源码设置 |
| 重排页面或资产 | 可复用编译和媒体产物，重新计算最终 ID 和链接布局 |
| 修改资产符号 | 按新符号检查当前引用，不自动修改控件或脚本 |
| 修改输出目录或并发数 | 可复用已有链接结果，在新位置发布产物 |
| 修改屏幕方向 | 更新相关页面和方向相关媒体；音频可继续复用 |
| 使用 `-Werror` | 重新按当前策略判断诊断，警告可能阻止发布 |

缓存位于 `.build/hmi-cache`，使用内容摘要判断输入及产物是否改变。缓存损坏或丢失会重新处理，工具更新也会使相关缓存失效。

链接缓存只保留最近一次有效结果，包含 HMI、链接映射和外部媒体。命中后仍检查当前工程，不复用旧的检查结论。

## 检查与输出

```powershell
hmi check panel
hmi check panel -Werror
```

`check` 不写构建缓存或 HMI。它检查页面、脚本引用、资产描述和工程布局；当前媒体探测可能执行完整解码，不能将它理解为只读文件头的快速检查。通过检查不保证后续实际编码或上位机的完整脚本编译一定成功。

构建时先完成编译、媒体处理、链接和 HMI 校验，再发布产物。配套文件先写入，HMI 最后原子替换。编译或检查失败不会更新原 HMI；多文件发布中途失败时，会报告已经写入的项目。需要整包独立保存时，可用 `-o` 输出到新的目录。

## 清理与工程锁

```powershell
hmi clean panel
```

`clean` 清理本工具登记且未被手动修改的构建产物，保留源文件、原始附件和 `dist` 中的最终输出。未登记的文件和内容已被修改的产物不会自动删除。若某个登记产物后来成为工程输入，清理会报告冲突并停止。

构建、重建和清理使用同一工程锁。同一工程正在被另一进程操作时会报错；进程退出后锁自动释放，不需要手工删除遗留的锁文件。

## 独立工具计划

```powershell
hmi plan panel -o plan
```

计划目录包含 `target.json`、`jobs.json` 和 `link.toml`，需要原始附件时还会复制 `original.hpo`。`jobs.json` 按命令名和参数数组描述独立调用，不是可直接执行的 shell 脚本。

`plan` 会检查工程并探测媒体，不生成 `.hmo`、`.hma` 或 HMI。按计划执行编译和媒体任务后，可用[独立链接器](../../hmi-linker/README.md)生成结果；其语义与统一构建入口一致。
