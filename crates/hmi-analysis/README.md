# 脚本辅助分析

[项目首页](../../README.md) · [公共库导航](../../README.md#公共库)

`hmi-analysis`（Rust 库名 `hmi_analysis`）提取脚本信息，并结合最终页面、控件和资源上下文检查引用与属性访问。

## 主要内容

| 模块职责 | 说明 |
|---|---|
| 脚本输入与分析结果 | 保存源代码上下文、词法标记及可用的位置。 |
| 工程上下文 | 提供当前名称、ID、属性和作用域。 |
| 引用检查 | 识别已支持的名称、常量名称组及页面跳转。 |
| 访问检查 | 检查部分只读、编译配置、页内属性及模式限制。 |

## 职责边界

当前实现不等于完整HMI 语言前端，不提供完整语法、表达式类型或方法签名验证。分析按当前名称和最终ID解释，不推断重命名历史。

## 开发入口

在工作区根目录查看 API 文档：

```powershell
cargo doc -p hmi-analysis --no-deps --open
```

各命令行工具调用共享库，不要求通过子进程复用。应用程序可按需要依赖该包；具体类型、函数和模块以生成的 Rust 文档为准。
