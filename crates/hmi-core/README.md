# 公共模型与规则

[项目首页](../../README.md) · [公共库导航](../../README.md#公共库)

`hmi-core`（Rust 库名 `hmi_core`）供所有阶段共享工程模型、目标能力和基础规则，避免各工具分别解释同一字段。

## 主要内容

| 模块职责 | 说明 |
|---|---|
| 工程与资产模型 | 工程、页面、链接清单、资源符号和媒体处理配置。 |
| 目标与控件 | 展开型号和方向，提供控件属性及系列限制。 |
| 诊断与文件 | 保留错误代码、位置和 I/O 信息，提供输入保护及原子输出。 |
| 执行报告与进度 | 记录任务、统计和产物状态，为 CLI 渲染和可选进度回调提供数据。 |

## 职责边界

不负责媒体转码、页面目标生成或最终 HMI 链接。工具使用者通常通过统一入口调用这些能力。

## 开发入口

在工作区根目录查看 API 文档：

```powershell
cargo doc -p hmi-core --no-deps --open
```

各命令行工具调用共享库，不要求通过子进程复用。应用程序可按需要依赖该包；具体类型、函数和模块以生成的 Rust 文档为准。
