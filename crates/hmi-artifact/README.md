# 目标文件与原始附件

[项目首页](../../README.md) · [公共库导航](../../README.md#公共库)

`hmi-artifact`（Rust 库名 `hmi_artifact`）定义工具阶段之间传递的自包含产物，并集中检查其描述、载荷和兼容约束。

## 主要内容

| 模块职责 | 说明 |
|---|---|
| 页面与程序目标 | `.hmo`保存编译结果、脚本信息、资源引用及重定位需求。 |
| 媒体目标 | `.hma`保存运行成员和实际已有的编辑源，可独立链接。 |
| 原始附件 | `.hpo`保留导入工程需要的记录和活动数据。 |
| 通用封装 | 统一元数据、载荷长度及摘要的读写；损坏或不兼容输入明确报错。 |

## 职责边界

产物不代替工程源码，也不跟踪对象历史身份。原始附件是工程输入，与可清理的派生产物分别管理。

## 开发入口

在工作区根目录查看 API 文档：

```powershell
cargo doc -p hmi-artifact --no-deps --open
```

各命令行工具调用共享库，不要求通过子进程复用。应用程序可按需要依赖该包；具体类型、函数和模块以生成的 Rust 文档为准。
