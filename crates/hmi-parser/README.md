# HMI 解析器

`hmi-parse inspect FILE.HMI --json` 查看目标配置、页面、控件及活动资源；`hmi-parse export FILE.HMI -o DIR` 导出新版工程。统一入口 `hmi inspect/import` 使用相同实现。

当前支持 ver21234、UTF-8、已内置型号配置、匹配目标画布几何的工程，并导入已接入变体的图片、ZI、动画、视频和音频。原生包保留运行成员与已有编辑源，不重新压缩；未知编码及非标准几何迁移仍明确拒绝，不静默丢弃。

已公开属性、事件和全局代码导出为可编辑文件；未开放字段、未知对象记录、页头及额外活动资源存入显式 `.preserve/origin.hpo`。已知字段、默认值、名称及ID仍以当前源码为准。原始定位只用于读取待保留数据，不用于跟踪改名或重排。

输出目录须不存在或为空，文件先暂存后发布。重建重新生成目录、偏移、引用和校验，不保存删除项、空闲区或旧分配历史；固定保留区域按已知格式规则生成。独立编译、链接均须显式提供声明的附件，不回读原HMI。

完整配置、边界及验收入口见[工具链使用说明](../hmi-cli/README.md#已有工程导入与原始数据附件)。
