# 目标型号配置

当前内置以下型号的基础工程数据，文件格式为 `ver21234`，字符编码为 UTF-8。

| 型号 | 新建 0°／180° 页面 | 新建 90°／270° 页面 |
|---|---|---|
| TJC4832K035_011 | 320×480 | 480×320 |
| TJC4832T035_011 | 320×480 | 480×320 |
| TJC3224T028_011 | 240×320 | 320×240 |
| TJC4827X543_011 | 480×272 | 272×480 |

配置来自空白工程、方向与型号对照实验。工程头标签分别为 1、0、0、3；它们不是通用的型号能力位。页面创建属性和默认启动代码在这些配置中已有独立生成及上位机打开、编译记录。

`default-program.s` 是这四组配置共同使用的默认启动代码，不含业务事件或私有资源。它作为程序内置数据分发，运行工具不需要本地逆向资料或 HMI 样本。

四个型号均开放 0°、90°、180°、270°。方向码分别为 0、1、2、3；90°／270° 的新建页面交换基础宽高。型号的 0° 基础尺寸来自原生新建记录，K035 四个方向已有历史构造验收，其中 90° 和 270° 还有当前实现的完整输出摘要回归；其他型号的新增方向按共同规则处理，并检查实际输出字段，不将其记为逐项上位机验收。

这些尺寸用于新建页面。导入已有工程时，不能仅因方向改变就交换原始页面几何；上位机可能保留原始记录，并按方向派生显示尺寸。

本表是当前已接入的型号配置，不是 HMI 格式的型号上限。目前四个型号均已接入热区、变量和定时器；其他控件及媒体能力按阶段增加。target.json 的 control_types 列出当前实现的控件类型，不代表型号本身只有这些硬件功能。
