# 空白工程配置

第一阶段内置以下型号的空白工程数据，文件格式为 `ver21234`，字符编码为 UTF-8。

| 型号 | 当前开放方向 | 序列化页面尺寸 |
|---|---|---|
| TJC4832K035_011 | 0°、270° | 320×480、480×320 |
| TJC4832T035_011 | 0° | 320×480 |
| TJC3224T028_011 | 0° | 240×320 |
| TJC4827X543_011 | 0° | 480×272 |

配置来自空白工程、方向与型号对照实验。工程头标签分别为 1、0、0、3；它们不是通用的型号能力位。页面创建属性和默认启动代码在这些配置中已有独立生成及上位机打开、编译记录。

`default-program.s` 是这四组配置共同使用的默认启动代码，不含业务事件或私有资源。它作为程序内置数据分发，运行工具不需要本地逆向资料或 HMI 样本。

当前仅开放已经接入第一阶段实现的组合。其他方向、普通控件和媒体能力将在后续阶段加入；本表不代表这些型号的完整硬件功能。
