# 目标型号配置

当前内置以下型号的基础工程数据，文件格式为 `ver21234`，字符编码为 UTF-8。

| 型号 | 新建 0°／180° 页面 | 新建 90°／270° 页面 |
|---|---|---|
| TJC4832K035_011 | 320×480 | 480×320 |
| TJC4832T035_011 | 320×480 | 480×320 |
| TJC3224T028_011 | 240×320 | 320×240 |
| TJC4827X543_011 | 480×272 | 272×480 |

配置来自空白工程、方向与型号对照实验。工程头标签分别为 1、0、0、3；它们不是通用的型号能力位。页面创建属性和默认启动代码在这些配置中已有独立生成及上位机打开、编译记录。

`default-program.s` 是这四组配置共同使用的默认启动代码，不含业务事件或私有资源。它作为程序内置数据分发，运行工具不需要本地逆向资料或 HMI 样本。

四个型号均开放 0°、90°、180°、270°。方向码分别为 0、1、2、3；90°／270° 的新建页面交换基础宽高。型号的 0° 基础尺寸来自原生新建记录，K035 四个方向已有历史构造验收，其中 90° 和 270° 还有当前实现的完整输出摘要回归；其他型号的新增方向按共同规则处理，并检查实际输出字段，不将其记为逐项上位机验收。

这些尺寸用于新建页面。导入已有工程时，不能仅因方向改变就交换原始页面几何；上位机可能保留原始记录，并按方向派生显示尺寸。

本表是当前已接入的型号配置，不是 HMI 格式的型号上限。控件及媒体能力按阶段增加，target.json 的 control_types 列出当前实现的控件类型，不代表型号本身只有这些硬件功能。

K/T 三组配置已接入 RGB565 图片及图片／切图控件；X543 的 JPEG 图片后端尚未接入。编码能力见 target.json 的 image_codecs，属于工具当前支持范围，不是型号硬件能力上限。

## 控件属性的型号差异

通用范围和默认值由控件注册表定义。`control-constraints.json` 只记录已经确认的系列／型号例外；没有条目时沿用通用范围。配置只涉及已经实现的普通整数属性，可表达连续范围和离散枚举，不会启用尚未实现的编码路线或控件模式。

当前文件中的 K0 规则如下：

```json
{
  "schema": "hmi.control-constraints/1",
  "series": {
    "k0": [
      {
        "control": "slider",
        "property": "psta",
        "constraint": { "kind": "range", "min": 0, "max": 1 }
      }
    ]
  },
  "profiles": {}
}
```

离散枚举使用 `{"kind":"values","values":[0,2]}`。两种形式互斥；范围上下限和每个枚举值必须落在通用属性范围内，枚举不能为空或重复，属性名称必须存在且为普通整数。文本和资源符号引用的规则由各自接口处理。

覆盖顺序为：通用属性范围 → 系列约束 → 单独型号约束。profiles 中以完整型号为键，值与 series 中相同，都是属性约束数组。同一控件／属性的型号条目替换系列条目，其他系列约束继续保留。单个数组内不允许重复声明同一控件／属性。

当前系列归属显式定义为：K035 属于 k0，T035／T028 属于 t0，X543 属于 x5，不通过型号名称猜测。新发现现有系列或型号的属性差异时，只需在 JSON 中增加条目，无需修改编译器、链接器或专用属性分支。未配置例外的型号按通用范围处理，这不表示每项功能都已经过硬件验收。

配置在构建工具时内嵌，运行时不依赖这个本地文件。解析后的规则摘要参与有效目标的指纹，排版与换行差异不影响摘要。更新内置规则并重新编译工具后，应重新生成 target.json 和相关 .hmo；target 的 control_property_constraints 保存已合并、按名称排序的规则。源码工程和分发版本号不因此改变。

## 控件支持状态

同一配置文件的 control_support 表记录已确认的控件系列限制。series 和 profiles 的键及覆盖顺序与属性约束相同，条目为 `{"control":"switch","supported":false}`；单独型号可以覆盖系列的同名控件状态。

没有条目时默认允许该已接入类型，具体是否具备媒体后端仍按工具实现能力检查。当前根据官方说明，在 t0／k0 中禁用 switch、combo_box、text_select、sliding_text；X543 按默认开放。这些状态展开到 target 的 control_types，源码编译和独立链接共用最终列表。未注册类型、同一作用域的重复声明或未知系列／型号会报错。
