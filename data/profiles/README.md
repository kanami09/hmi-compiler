# 目标型号配置

[项目首页](../../README.md) · [工程配置](../../crates/hmi-cli/reference/project.md) · [控件参考](../../crates/hmi-compiler/reference/controls.md)

## 已支持配置

| profile | 系列 | 0°基础尺寸 | 图片编码 |
|---|---|---|---|
| `TJC4832K035_011` | K0 | 320×480 | RGB565 |
| `TJC4832T035_011` | T0 | 320×480 | RGB565 |
| `TJC3224T028_011` | T0 | 240×320 | RGB565 |
| `TJC4827X543_011` | X5 | 480×272 | JPEG，可保留透明度 |

四个配置均支持 0°、90°、180°、270°。新建页面在90°／270°时交换基础宽高。已有工程的实际页面几何可能与切换方向后的标称画布不同；不支持的导入几何差异会报错。

这些是本工具已接入的目标配置，不代表HMI型号上限。新增型号还需要相应工程配置，不能仅靠名称相似推断支持。

```powershell
hmi target list
hmi target show TJC4827X543_011 --orientation 90
hmi target export TJC4827X543_011 --orientation 90 -o target.json
```

## 控件与属性限制

`target.json`的`control_types`列出该配置开放的控件，`image_codecs/font_versions`列出媒体能力。约束反映工具实现范围，不是硬件全部能力的声明。

内置T0/K0配置不开放状态开关、下拉框、选择文本、滑动文本、文件浏览器、文件流、数据记录、外部图片、动画、视频和音频。X543开放已接入的这些类型；音频能力仍需结合具体设备确认。

常见属性差异：

| 属性 | T0/K0 | X543 |
|---|---|---|
| 文本、按钮、数字、虚拟浮点、双态按钮、滚动文本的背景`sta` | 0～2 | 0～3，含透明 |
| 指针背景`sta` | 0～2 | 0～3，含透明 |
| 页面及支持控件的`effect` | 0 | 0～8 |
| 支持控件的`drag/aph` | 0／127 | 0～1／0～127 |
| 滑块游标`psta` | K0为0／1，T0使用通用0／1／2 | 0／1／2 |

属性的含义、必填条件和其他范围见[控件参考](../../crates/hmi-compiler/reference/controls.md)。没有特别约束的已支持属性使用其通用范围。

目标配置随工具提供，普通用户不需要修改仓库内的数据文件。工具或目标规则更新后，可重新导出`target.json`并重建相关目标文件。
